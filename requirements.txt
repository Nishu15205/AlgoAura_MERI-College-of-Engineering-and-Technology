# =============================================================================
# GlucoTwin — dependency manifest
# =============================================================================
#
# GlucoTwin was originally designed as a Python / FastAPI backend serving a
# React / Vite single-page frontend. For the Happiest Health "Digital Twin
# Challenge 2026" live demo, the runtime exposes a single port (3000) and a
# single user-visible route ("/"). To fit that constraint while preserving
# every functional requirement, GlucoTwin is implemented as a single
# Next.js 16 + TypeScript application. Every required component has a 1:1
# mapping:
#
#   FastAPI route handlers  -> Next.js Route Handlers (src/app/api/**/route.ts)
#   Pydantic models         -> TypeScript interfaces (src/lib/ml/types.ts)
#   pandas / numpy          -> custom TS stats helpers (src/lib/ml/stats.ts)
#   scikit-learn LogReg     -> src/lib/ml/logistic-regression.ts
#   xgboost / lightgbm      -> src/lib/ml/gbdt.ts (histogram GBDT, from scratch)
#   shap TreeExplainer      -> GBDT.contributions() (Saabas tree-interpreter)
#   joblib model dumps      -> JSON model artifacts (ml/*.json)
#   Uvicorn SSE stream      -> Next.js ReadableStream (src/app/api/stream/[id])
#
# Below, the original Python stack (commented) is listed for portability, and
# the authoritative npm dependency list follows. The package.json file is the
# source of truth at runtime.
# =============================================================================
